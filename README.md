# Project title

E-commerce Customer Intelligence & Retention Analysis

# Project Overview

This project analyzes customer purchasing behavior, retention patterns, and revenue trends using transactional e-commerce data. The goal is to generate actionable insights that support business growth and customer retention strategies.

# Business Problem

The company wants to understand:
- Which customers generate the most revenue
- How customer retention changes over time
- Which products drive sales growth
- Opportunities to improve customer loyalty

  # Dataset
Single table  that contains :
- product details
- customer details
- sales data


Key Fields:
- Customer ID
- Order Date
- Product Category
- Revenue

  # Data Cleaning

Performed the following:

- Standardized date formats

  # Analysis

- Revenue Analysis
- Customer Segmentation
- Cohort Retention Analysis
- Product Performance Analysis
- KPI Tracking


# Key Insights

- 18 Millions of revenue contributed by Premium customers amoung customer segments.
- January 22.18% and February 20.24% showed highest retention rate.
- the product category Sports , Books and Beauty drives the most quantity sold.


# Recommendations

- improve retention rate through customer satisfaction and market campaigns with strong focus on premium customers.
- Promote high-performing product categories including sports, Books and beauty.
- Reduce time-to-first-purchase through onboarding incentives.
